# About VIVA+

VIVA+ is a line-up of open source finite element models of vehicle occupants and standing road users.

The baseline model is an average female (50F). Three other models are maintained as part of the main repository - average male (50M), standing average female, and standing average male.

More positioned models contributed by the [VIVA+ user community is also available](../contributor-guide/positioned-models.md). These may not be however updated to the latest stable release.

## VIVA+ Maintainer Team

VIVA+ models were developed in the [project VIRTUAL](https://projectvirtual.eu/) and has been since maintained by a team.
